# M.A Sabor Caseiro

Cardápio digital responsivo em React + Vite, com identidade visual inspirada no material enviado.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação

O projeto pode ser importado na Vercel como uma aplicação Vite. Os comandos padrão são `npm run build` e diretório de saída `dist`.

## Conteúdo

Os itens, preços e telefone estão em `src/main.jsx`. Confirme os valores e descrições com a loja antes de publicar.
